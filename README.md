## Облік прогресу
`audit/audit-log.csv` має один рядок на картку. `pending` — змістовий аудит ще не зафіксовано; `needs_review` — знайдено питання; `passed` — перевірено; `fixed` — виправлено і повторно перевірено. Технічно повна картка не вважається змістовно перевіреною.

Команда автоматичної перевірки: `node scripts/check-data.mjs`. Цей тест перевіряє структуру, а не мовну правильність.

Перші питання: **一体 (13, 612)**, **先日 (230, 3890)** та **相当 (1634, 3363)** — повторні написання, які треба розглянути вручну перед будь-яким об'єднанням.

## Уточнення правил карток — версія 26

- Для іменників із дієслівним уживанням (〜する) відділяємо іменниковий переклад від дієслівного; приклад: 悪化 — «погіршення»; 悪化する — «погіршуватися».
- «Різниця (нюанси)» у словниковій картці відображається тільки для реальних споріднених/синонімічних позицій із рекомендацій; антоніми показуються виключно у своєму розділі. Якщо таких порівнянь немає, розділ приховано.
- У картці 〜ようが найближчим граматичним зіставленням поставлено 〜ようが～まいが. Менш близькі 〜とはいえ та 〜といえども прибрані саме з рекомендацій цієї картки.
- Це початок послідовної перевірки частин мови та перекладів усієї бази; **не означає**, що подібні записи вже виправлено скрізь.

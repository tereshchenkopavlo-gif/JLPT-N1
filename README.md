Версія 18 — початкова контрольна точка. Затверджений інтерфейс, читання та збереження прогресу не змінюємо без причини.

- **3914** словникових карток: японське визначення, український переклад, 2 приклади, споріднені слова і нюанси.
- **130** граматичних карток: визначення, переклад, 2 приклади, споріднені конструкції та відмінності.

- Повний фінальний автономний HTML.

## Облік прогресу
`audit/audit-log.csv` має один рядок на картку. `pending` — змістовий аудит ще не зафіксовано; `needs_review` — знайдено питання; `passed` — перевірено; `fixed` — виправлено і повторно перевірено. Технічно повна картка не вважається змістовно перевіреною.

Команда автоматичної перевірки: `node scripts/check-data.mjs`. Цей тест перевіряє структуру, а не мовну правильність.

Перші питання: **一体 (13, 612)**, **先日 (230, 3890)** та **相当 (1634, 3363)** — повторні написання, які треба розглянути вручну перед будь-яким об'єднанням.

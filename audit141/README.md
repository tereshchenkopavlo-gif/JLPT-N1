# Відтворення v141 — 265 збережених наборів питань

```sh
python3 audit141/build.py
python3 audit141/check.py
node --check audit141/app.js
npm install --no-save playwright@1.56.1
npx playwright install --with-deps chromium
node audit141/meaning-browser.cjs
node audit141/presentation.cjs
node audit141/ui.cjs
node audit141/browser-functional.cjs
node audit141/session-completion.cjs
node audit141/comparison-browser.cjs
python3 audit141/publish.py
```

Повний HTML збирається з опублікованого v140 з фіксованим SHA, без завантаження навчальних даних з мережі. `author.py` містить 12 адресних змін наборів і одне уточнення японського визначення 身代金. `decisions.tsv` — 265 індивідуальних авторських рішень. `review.py` прив’язує їх до обох чинних прикладів, усіх варіантів, пояснень та хешів payload; окремо обліковується runtime-набір g95.

`check.py`: 19 груп інваріантів, точний дозволений diff, незмінні ID, дані, тексти, приклади, порівняння, стилі й сховище. `meaning-browser.cjs`: 530 лексичних +2 граматичні контексти ×4 розташування ключа =2128 фактичних генерацій; 532 ×3 ширини =1596 показів із натисканням неправильної відповіді, перевіркою ключа, пояснення та переповнення. Перестановка варіантів і вибір прикладу контролюються лише в тестовому браузері; у HTML тестових механізмів немає. Додатково перевірено відсутність перенесення примітки першого прикладу на стороннє невідоме речення для шести багатозначних слів.

Регресії: картки/POS/пошук/фільтри, гортання кнопками/клавішами/свайпами, асинхронна навігація, порівняння, backup/import/reload, повна звичайна сесія та 12 сценаріїв теми/масштабу 比較. Сценарії перенесено з v140 з явним шляхом нового HTML; результати обчислюються заново й мають його SHA.

`publish.py` допускає публікацію тільки після проходження перевірок, зараховує у completion/review-register.csv рівно 265 наборів (не повних карток) і створює повний HTML, аудит та поточні документи. Незалежна мовна експертиза, всі випадкові генерації C11 й інші відкриті задачі не оголошуються завершеними. Практичний Android/Windows цими Chromium-тестами не замінено. Потрібен CJK-шрифт для візуального огляду.

Незавершений контрольний стан: work/v141-checkpoint, commit 5dc0023a8878ce6f90465af078222bc435c4cb79. Він зберігає редакторські джерела до фінального gate й не є готовим випуском. Походження нових змін і невизначеність успадкованого матеріалу — sources.md та provenance.json; юридичного очищення не заявлено.

# Відтворення v154

Основа — точний повний HTML v153. Застосування та перевірка:

```sh
python3 audit154/apply.py JLPT_N1_ukrainian_reading_v153.html JLPT_N1_ukrainian_reading_v154.html
python3 audit154/verify.py JLPT_N1_ukrainian_reading_v153.html JLPT_N1_ukrainian_reading_v154.html
```

Поіменні цілі й вихідні хеші — translations.tsv та pilot-fields.tsv. Поточний обсяг і контрольна сума — scope.json. Поля японських визначень і українських перекладів є авторськими редакціями за попередніми рішеннями аудиту. Зміни повторно прочитані в контексті незмінених японських прикладів. Поточна правка не закриває походження давніших матеріалів.

Зворотна підстановка змінених даних, загальної відповіді v_293 і заголовка відтворює вихідний v153 побайтно. Перевірка охоплює 3914 ID слів, 130 конструкцій, незмінність усіх інших даних і коду, показ 52 перекладів спільною функцією та синтаксис JS.

Браузерні сценарії взято з audit152 і запущено для цієї збірки в work/v154-checkpoint. Тести й повний журнал прив’язані до конкретного commit і SHA-256 у файлі аудиту. Ці тести проводяться в Linux Chromium. Приймання на фізичних Android/Windows і незалежна мовна експертиза мають окремий облік.

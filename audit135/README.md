Для візуального перегляду потрібний CJK-шрифт, наприклад Noto Sans CJK JP (у CI пакет fonts-noto-cjk). Скріншоти m135-08, l135-04, l135-05 і картки на 412px створюються в /tmp. Усі 18 нових текстів перевіряються на 360/412/1280px: 54 відображення/126 відповідей. Вибір тексту здійснюється тестовою маршрутизацією всередині справжнього генератора; у випуску немає тестових гачків. Окрема повна сесія запускається без інструментації. Функціональні звіти перевіряють ненульовий штучний прогрес слів/граматики та порівнянь після import/export/reload, а не прогрес користувача.

`publish.py` вимагає SHA-256 фінального HTML і відповідності йому всіх звітів, після чого копіює повний HTML у корінь і готує аудит/README/PROJECT_STATUS. Кількість дій оцінки в повній сесії може відрізнятися через випадковий вибір тексту; це не число унікальних карток. Публікувати лише після успішного gate; після публікації звірити Git blob SHA HTML, аудиту й документації з main.

# JLPT App N5–N1 — стратегічний пакет

Погоджена користувачем зміна напряму: **4 листопада 2026, Asia/Tokyo**. Кінцева мета — самостійний публічний застосунок усіх п’яти рівнів. Поточний пріоритет — завершальний наскрізний аудит наявного N1, без масового розширення, перенесення рівнів, видалення матеріалу або зміни навчальних алгоритмів.

- [Поточний стан і межі перевірки](STATE_SNAPSHOT.md), [машинний знімок](snapshot.json).
- [Походження матеріалів і попередній реєстр ризиків](PROVENANCE_REVIEW.md), [джерела/умови](source-register.json), [поелементний облік](asset-register.csv).
- [Майбутня класифікація та міграція](CLASSIFICATION_ROADMAP.md).
- [Методологія ефективного навчання JLPT](LEARNING_METHODOLOGY.md) — документ для архітектурного Work-чату.

Перші документи є підготовкою й рекомендаціями. Походження, авторська заява, мовна правильність, юридична придатність до публікації та навчальна ефективність обліковуються окремо. `unknown` не означає встановленого порушення, а `authored_claim` — юридичного очищення. Немає дозволу правовласника книги, який можна було б вивести лише з дозволу користувача прикріпити/використати PDF.

Відтворення поточного знімка: `python3 strategy/inventory.py`. Скрипт читає перевірений повний v139, не змінює HTML, прогрес, попередню baseline чи статуси мовного аудиту. Поелементний реєстр зберігає хеші, а не копії зовнішніх текстів. Подальші рішення вносити зі збереженням історії та доказу; масового юридичного очищення не заявлено.

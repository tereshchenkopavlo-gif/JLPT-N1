# Уже опубліковані HTML: окремий аудит ризиків

5 листопада 2026, Asia/Tokyo. Це оцінка наявного публічного поширення, **не лише майбутнього JLPT App**. Знімок GitHub зроблено на `main` commit `571aa092d256e682ad16873b7462dcc263cf62d8` / v141; v140 лишається окремим опублікованим файлом. Аудит встановлює канали й пріоритети перевірки, а не доводить порушення чи надає юридичний дозвіл.

Докази: [public-inventory.json](../review20261105/public-inventory.json) — файли, blob SHA, SHA-256 поточних HTML, гілки й історія; [api-state.json](../review20261105/api-state.json) — метадані GitHub на дату знімка; [відтворення](../review20261105/README.md). Походження полів навчальної бази — у попередньому [PROVENANCE_REVIEW.md](PROVENANCE_REVIEW.md) та історичному asset-register.csv; ці документи не переписано як нібито завершене очищення.

## Правова рамка й висновок для поточного поширення

За [文化庁, 著作権テキスト 令和8年度](https://www.bunka.go.jp/seisaku/chosakuken/seidokaisetsu/pdf/94383901_01.pdf), творчі визначення/тексти, переклади/адаптації й творчий добір або розташування збірника потребують окремого розгляду. Розміщення охоронюваного матеріалу у стані доступності для інтернет-передавання також має значення; чекати першого завантаження для виникнення питання про права не потрібно. Виняток приватного копіювання не є автоматичним дозволом на публічне поширення навчального HTML. Див. друковані сторінки 7, 16–17, 22, 65 цього видання.

[Офіційна схема 文化庁 щодо використання чужих творів](https://www.bunka.go.jp/seisaku/chosakuken/seidokaisetsu/chosakukensha_fumei/) вимагає з’ясувати охоронюваність, строк, застосовний виняток або права на використання. Окреме загальновживане слово, коротке типове речення й повна добірка з поясненнями — різні предмети оцінки. Переклад, нова нумерація чи мовне редагування самі по собі не доводять незалежного походження.

[Умови GitHub, розділ D](https://docs.github.com/en/site-policy/github-terms/github-terms-of-service#d-user-generated-content) покладають на того, хто розміщує контент, відповідальність за право його публікувати. [Документація про ліцензування](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/licensing-a-repository) відрізняє публічний перегляд/форк від загальної ліцензії. API не виявив ліцензії репозиторію; це не доказ ані отриманого дозволу на книгу, ані встановленого порушення. Додавання власної MIT/CC-ліцензії не створило б права на сторонній матеріал.

**Наш висновок щодо пріоритету:** ризик треба перевіряти вже для наявного публічного N1, а не відкладати до майбутнього комерційного App. Це висновок із установлених каналів доступу й невизначеного походження, не оцінка судом і не встановлення, що кожний запис захищений або запозичений. Юридичне рішення для конкретного матеріалу й юрисдикції має спиратися на зіставлення, дозволи/ліцензії та застосовні винятки.

## Практичні наступні дії без втрати історії

1. Використовувати цей знімок для зіставлення джерел; прив’язувати рішення до blob/поля й усіх відомих носіїв, не лише до назви «актуальна версія».
2. Почати ручне зіставлення P1 з виданням і відомими джерелами. Реєструвати точне/близьке використання та оригінальне написання окремо від лінгвістичної правильності. Відсутність збігу пошуку не є доказом оригінальності.
3. Для Actions спочатку звірити вкладення/хеші контейнерів; дата майбутнього закінчення строку зберігання не є правовим рішенням і не усуває вже зроблених копій.
4. Перед окремим рішенням про очищення/обмеження доступу зберегти контрольований доказовий архів і перелік носіїв. Лише потім обирати, що потрібно для поточних файлів, історії, гілок, артефактів і зовнішніх копій. Зміна видимості теж не повертає вже завантажене.
5. Питання зміни видимості, видалення публічних матеріалів, переписування Git-історії, дозволу правовласника або звернення до нього — окремі рішення. У цьому проході таких дій не виконано й повідомлень нікому не надсилали.

Збереження чинної бази й попереднього аудиту не є твердженням про правове очищення. Подальший мовний аудит і проєктування N5–N1 можуть тривати з таким розділеним обліком; вони не підміняють перевірку вже наявного поширення.

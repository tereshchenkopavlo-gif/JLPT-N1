Основа — повний v138, точний SHA перевіряється build/check. Janome не потрібен: proposals.json зберігає пропозиції, author.py — виправлені й авторськи прочитані точні форми та 10 граматичних контекстних наборів. Реєстр 526 рішень створюється окремо від історичної діагностики. 237 нових exact-форм +30 C04, одна заміна прикладу 網; усі стабільні ID збережено. Генератор не пропонує cloze для цих адресних форм; читання явно стосується заголовка. Попереднє повне meaning-пояснення збережене для записів без контекстного quiz.

check.py/scan.cjs виконують реальний старий і новий markTarget для всіх 8089 прикладів, звіряють усі 526 рішень та негативну область exact-реєстру. Браузерний прогін вибирає кожен із 556 контекстів (526 C05 +30 C04) і три позиції вибору типу на 360/412/1280px: 5004 генерації. Усі 556 показано й перевірено відповідь на 412px; додатково 267 точних форм на 360/1280px, разом 1090 показів. Тестове керування Math.random не входить у фінальний HTML. Воно не є перевіркою кожної випадкової комбінації альтернатив C11.

identity-browser.cjs експортує справжній backup v138 з тестовим прогресом ID716, імпортує у v139, перевіряє reload, новий заголовок, POS і старі порівняння. Збереження користувацьких CSV-наборів не змінене; їхні власні заголовки не мігруються як вбудована база.

Інші сценарії перевіряють форматування без втрати змісту, POS/пошук/фільтри, гортання, порівняння, backup/import/reload, повну сесію та 12 комбінацій теми/масштабу/ширини з типографікою v138. Для візуального огляду потрібен CJK-шрифт. Це Chromium/file://, не фізичний смартфон. Межі мовного перегляду: sources.md. Усі звіти прив’язані до фінального SHA-256.

Після успішного gate publish.py створює повний HTML, аудит, докази C05/C06 і оновлює поточні документи. main повинен містити повний HTML та аудит, а не лише скрипти; завершальна звірка — git blob SHA. Робочий незавершений checkpoint збережено окремо у work/v139-checkpoint.

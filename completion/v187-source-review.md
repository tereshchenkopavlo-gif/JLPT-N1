## Verified distinctions

- `仮に`: `費用面の負担はどうなるのか` asks what the financial burden will be; it does not ask how the burden is allocated.
- `根本的な解決`: fundamental/root solution; “final resolution” is too narrow.
- `再発防止策を徹底する`: thoroughly implement recurrence-prevention measures; avoid the literal “measures against its recurrence”.
- `わざと間違える`: deliberately make a mistake; not “pretend a mistake”. In `隠していたとして`, preserve the basis/evidential nuance.
- `当然`: Kotobank / Digital Daijisen classifies it as 名・形動 and 副; app POS map currently lists only 副詞. Hold ID644 for C11.
- `オーバー`: Kotobank / Digital Daijisen classifies it as 名 and 形動; app POS map currently lists only 名詞. Hold ID663 for C11.
- `インフルエンザ`: Kotobank defines it as an infection caused by influenza virus, not by an arbitrary virus.
- `ウイルス`: Digital Daijisen describes replication in living cells; the revised Japanese definition avoids circular wording.
- `カウンター`: dictionary senses include counter/table, counter, and 反撃・反抗; the Ukrainian gloss should not omit the counterattack sense.
- `ベース`: dictionary distinguishes base (including baseball base) from bass (low register / bass guitar); the gloss now covers the senses already explained in usage.
- `間もなく / やがて`: no categorical difference added. Kotobank's やがて entry includes “before long/soon” and lists 間もなく among its equivalents; the existing usage note is adequate without an artificial strict boundary.

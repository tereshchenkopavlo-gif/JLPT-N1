# C11 — перевірка складу пулів перед публікацією

18 листопада 2026. v230 пройшла GitHub Actions #44110159445; її технічний та авторський checkpoint — b27845ff727b3ebd4d64ab6bf72984010662e3d5. Звірка складу пулів нижче є окремою перевіркою перед випуском.

На 3914 стабільних ID викликано оригінальні quizReadingOptions і clozeWordCandidates із чинних HTML, порівняно впорядковані списки для вбудованого ACTIVE_VOCAB (без імпортованих користувацьких наборів). v230 порівняно з опублікованою v229. Для v231 застосовано лише три запропоновані POS-зміни до того самого v230; це прогноз складу, не запуск повного v231.

- v230: 5 змінених reading-пулів (4 поза 12 картками). ID3375 і ID3389 перетинають поріг трьох. 2928 змінених cloze-пулів (2916 поза партією). ID3892 перетинає поріг сирого пулу, але браузерна перевірка не зафіксувала зміни доступності його прикладів.
- v231: 2630 змінених cloze-пулів, зокрема 2626 поза чотирма картками. Змін у reading-пулах не виявлено.
- Структурна доступність і склад пулу не підтверджують семантичну якість варіантів. Новий cloze-вміст не додавався.

Публікацію в main заблоковано вимогою зберегти поведінку інших наборів. Позначки POS підживлюють глобальні пули. Наступне рішення — відокремити відображення POS від правил добору вправ або погодити окремо обґрунтовані зміни пулів. До рішення не надавати нового реєстрового кредиту в main і не публікувати HTML. Незалежне та фізичне приймання залишаються відкритими.

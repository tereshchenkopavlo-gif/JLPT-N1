# C11 — розділення позначок карток і класифікації вправ

`VOCAB_POS_BY_ID` через `vocabPartOfSpeech` живить позначку на картці, фільтр за частиною мови та обидві функції добору відповідей: `quizReadingOptions` і `clozeWordCandidates`. Ці функції застосовують однакову POS-сигнатуру до цільового слова і кожного кандидата в `ACTIVE_VOCAB`, включно з імпортованим набором. Тому зміна одного ярлика змінює пул також для інших карток.

Наприклад, 当面 (ID3375) отримує 名詞・副詞 замість 副詞. У v230 його пул читання скоротився з 4 до 0, а ID3389, якого не редагували, також утратив достатню кількість варіантів. だぶだぶ (ID3417) отримує 副詞・ナ形, а його сирий cloze-пул скоротився з 276 до 4. Для v231 перехід ユニーク (ID3652) і ルーズ (ID3677) до ナ形 також змінює пули інших карток. Деталі — у global-pool-publication-hold.md.

Відображення й фільтри використовують лінгвістичні позначки. Окремий пошук POS для вправ фіксує сигнатури v229 для ID із погоджених партій v230/v231; для інших ID діють ті самі правила, включно з резервним 連語. Це рішення зберігає попередній добір, тому його результати самі по собі не підтверджують якість альтернатив. Точні meaning-перевизначення і вимоги до reviewed cloze залишаються окремими.

## Перевірка робочого кандидата

- Node виконав функції з HTML. Склад і порядок reading та cloze збіглися з v229 для всіх 3914 вбудованих ID, а також для контрольного набору з 2611 записів зі зміненим порядком і новим ID. ID3375 та ID3389 зберігають щонайменше три альтернативи читання.
- Той самий тест пройшов з трьома POS-змінами з чинного v231 payload. Це перевірка впливу класифікації v231 на пули. Повного HTML v231 не зібрано.
- Синтаксис скриптів HTML пройшов перевірку. Зміни HTML обмежені таблицею сумісності та чотирма викликами добору. Авторські POS, приклади, meaning, reviewed cloze, фільтри, механізм імпорту й збереження прогресу залишилися в точному вигляді з checkpoint v230.
- Chromium у поточному середовищі не стартує: системний виклик socket завершується з Operation not permitted. Потрібен браузерний прогін цієї збірки, включно з реальним імпортом і прогресом. Незалежне мовне приймання відкрите.

Для відтворення зміни застосувати `python3 completion/v230-work/isolate-pos.py` до незміненого HTML v230 з checkpoint. Для перевірки запустити `node completion/v230-work/test-pos-isolation.cjs PATH_TO_V231_PAYLOADS_JSON`, використовуючи `completion/v231-work/payloads.json` із гілки v231.

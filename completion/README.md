# Робочий пакет завершення 1.0

**Поточне доповнення:** C04 закрито у v137; [C04-result.json](C04-result.json) та audit137/scan-results.json містять нові докази. Наведені нижче baseline/target-diagnostics/target-triage залишаються історичною основою v135/v136. Їхні 30 unmarked не описують поточний v137, у якому їх 0.

- [PLAN.md](PLAN.md) — погоджена мета, межі й критерій зупинки.
- [BACKLOG.md](BACKLOG.md) — єдиний список незавершених задач і докази закриття.
- [baseline.json](baseline.json) — точні лічильники v135, контрольна сума й залишок 21/19 текстів.
- [review-register.csv](review-register.csv) — поелементне приймання 1.0; історичні перевірки не обнуляються.
- [reading-inventory.json](reading-inventory.json), [grammar-contexts.json](grammar-contexts.json) — точні тексти та наявні авторські контекстні примітки. Ця карта ще не є перевіркою всіх значень чи всіх входжень у старих текстах.
- [target-diagnostics.json](target-diagnostics.json) — повторний технічний прогін фактичного markTarget: 8089 прикладів, 30 без збігу й 526 однознакових кандидатів.
- [target-triage.json](target-triage.json) — класифікація всіх 30 незбігів і технічне групування 526 кандидатів; виправлення HTML і змістові висновки ще потрібні.
- [reconciled-v135.json](reconciled-v135.json) — зараховані попередні авторські перевірки 18 текстів/42 питань; не незалежний аудит.

Відтворення з кореня репозиторію:

```sh
python3 completion/inventory.py
python3 completion/reconcile-v135.py
python3 completion/triage-targets.py
```

Потрібні Python 3 і Node.js. Сканер виконує незмінений метод markTarget із SHA-перевіреного v135 у Node vm без DOM. Він перевіряє збіг/межі, а не відображення в браузері або мовну правильність. Для зміни форми чи прикладу додатково потрібен реальний прогін відповідної сесії. Скрипти працюють з окремим завершальним реєстром і не редагують попередні звіти чи HTML.

`inventory.py` за повторного запуску перевіряє сталість складу реєстру та зберігає його статуси/докази. Нові 40 текстів і їхні питання додаються до реєстру явно під час відповідних випусків; лічильники, джерело й контрольна сума тоді оновлюються окремим переглянутим кроком. Поки це зафіксована початкова основа v135.

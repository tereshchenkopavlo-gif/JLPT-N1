## Source-specific notes

- **合席 / 相席 (1251):** Kotobank, 精選版 日本国語大辞典, entry 合い席, lists the forms `相席・合席` together and defines them as sitting at the same table with unfamiliar customers in an eating/drinking establishment. The existing usage note that 相席 is the more common spelling is retained; the headword is not renamed.
- **古来 (1202):** POS-map remains 名詞. The adverbial example `古来、` is a standard adverbial use of a noun; the separate model `古来の` confirms the nominal pattern. No POS change is made, so no unverified quiz-candidate side effect is introduced.

No other external source was added. No Japanese example changed except ID1237, second example; its target/quiz maps do not contain the old sentence and remain unchanged.

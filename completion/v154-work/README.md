# Робоча збірка v154

Перша партія правок містить 32 українські переклади прикладів із трьох попередніх партій аудиту. [Поіменний перелік](translations.tsv) вказує ID, номер прикладу від нуля, SHA-256 вихідної картки й попереднє рішення. Дані та перевірки походження мають окремий облік.

З кореня репозиторію збережіть робочий HTML командою:

```sh
python3 completion/v154-work/apply.py JLPT_N1_ukrainian_reading_v153.html JLPT_N1_v154_working.html
```

SHA-256 очікуваного HTML — `9893552e3d6c592a2066853e512831374744b228be548b1b867692d3f37d3943`. Розмір 6928293 байти.

Порівняння з v153 підтвердило зміни рівно в 32 перекладах. Після їх зворотної заміни відтворюється вихідний HTML. Усі вбудовані скрипти пройшли `node --check`. Спільна функція показу прикладів у картках і порівнянні сформувала правильну пару японського речення та українського перекладу для всіх 32 змін. Локальний Chromium заблоковано під час запуску через заборону створення сокета. Браузерна регресія лишається відкритою. Збірка робоча, поточний випуск — v153.

Наступний неперевірений ID — 1281. Реєстр покриття v153 зберігає попередні результати. Для наступних партій цієї збірки варто групувати незалежні правки перекладу окремо від змін, які зачіпають японські речення, частини мови, порівняння або генерацію вправ.

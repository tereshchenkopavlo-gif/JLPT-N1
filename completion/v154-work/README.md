# v154 — checkpoint

Робоча збірка містить 44 українських перекладів і три правки основних полів. [Переклади](translations.tsv) та [поля пілота](pilot-fields.tsv) прив’язані до контрольних сум карток v153. Перенесено чотири відкриті рішення з [приймання пілота](../v153-acceptance.md), ID 222, 254, 291 і 293. Для 293 узгоджено загальну відповідь вправи з дефініцією. Обидві чинні контекстні відповіді й альтернативи прочитано повторно та збережено. Ще чотири переклади взято з перегляду ID 1381–1480.

З кореня репозиторію:

```sh
python3 completion/v154-work/apply.py JLPT_N1_ukrainian_reading_v153.html JLPT_N1_v154_working.html
```

SHA-256 очікуваного HTML — `66d1a42cb58a1083018b612a99f026dbccacdd9ec466a4564c07a0a37a5346d4`. Розмір 6928146 байтів.

Зворотна підстановка 44 перекладів, трьох основних полів та однієї загальної відповіді вправи відтворила v153 побайтно. Звірено 3914 ID слів, 130 конструкцій, прив’язку двох контекстів 293 і рендеринг 44 перекладів через спільну функцію карток і порівнянь. Вбудований JS пройшов перевірку синтаксису Node. Локальний Chromium завершується під час створення сокета, тому браузерний прогін точного HTML ще потрібен. v153 лишається чинним випуском.

Наступні дії. Для 255 і 278 перевірити частини мови разом із фільтром і генерацією вправ. Прогнати в браузері картки зі зміненими полями, обидва контекстні завдання 293, порівняння та збереження прогресу. До приймання не переносити зарахування з checkpoint. Наскрізний перегляд продовжувати з ID 1561.

## Повторний прогін рушія

Використано [прогін пілота](https://github.com/tereshchenkopavlo-gif/JLPT-N1/blob/cbae2e232b74c4e35205589853d6685ccb527acb/audit-pilot/follow-up.cjs) з параметром `--meaning` на точному HTML checkpoint. У чотирьох згенерованих контекстах 展開 і 破壊 перевірено виділення цілі, стабільний ключ, текст правильної відповіді, три альтернативи й пояснення. Обидва контексти 破壊 пройшли.

Окремо в пам’яті змінено класифікацію 255 і 278 й викликано ті самі функції добору. Проба дала такі результати.

| ID | Пробна позначка | Кандидати для читання | Пул для пропусків |
| --- | --- | --- | --- |
| 255 直接 | 名詞・副詞 | 6 → 0 | 2298 → 16 |
| 278 同士 | 名詞・接尾辞 | 6 → 0 | 2298 → 0 |

Ці кількості вимірюють роботу добору, а не мовну якість альтернатив. Жодну пробну позначку в HTML checkpoint не внесено. Наступний крок для цих двох ID — визначити, чи можна перевірити читання й суфіксальне вживання адресними наборами завдань без зміни загального добору. Потрібен браузерний прогін. Актуальна межа наскрізного аудиту в main — ID 1561.

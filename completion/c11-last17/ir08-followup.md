# C11 · звірка IR08

Авторські правки за незалежними зауваженнями IR-20261121-08, з точними реченнями пакета. У 3375 обидва контексти тепер перевіряють часовий зміст 当面. Для 当面は ключ більше не повторює зміст 現状維持. Пояснення 当面の課題 відділяє поточний етап від терміновості. У 3652 другий контекст отримав альтернативу про відтворюваність дослідження замість варіанта, що використав згадку про нагороду. Решту формулювань для цих двох ID узято з пакета IR08.

Тест: змінено лише дві позиції у REVIEWED_MEANING_QUIZZES, усі байти поза цим блоком збігаються з попереднім кандидатом. По чотири різні варіанти, синтаксис JS пройшов. SHA-256 `f13275efe68643c9acdbdefd513b829f7d28afd4b7444bd9647f2d12053a7237`.

Рецензент IR08 відзначив pass для 3417, 3444 і 3565. У 3417 значення meaning_quiz збігається з пакетом, для 3444 і 3565 є розходження. Для цих двох потрібна звірка на рівні полів перед перенесенням кредиту. Цей крок не переносить рішення на інші поля навіть для 3417.

Нові формулювання 3375/3652 ще потребують незалежного повторного перегляду і Chromium. Реєстр 3897/3914, ID1510 окремо pending.

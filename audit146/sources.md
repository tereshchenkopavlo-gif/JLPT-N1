# Джерела й межі перегляду v146

Партія охоплює g33–g56, 48 японських прикладів з українськими перекладами та 17 порівнянь. Пояснення звірено з конкретними прикладами й наявними ключами до вправ. Поіменні рішення наведено в editorial-review.json.

- Для べくもない використано попередню словникову звірку значення неможливості з デジタル大辞泉. [Джерела v143](../audit143/sources.md)
- Для いざしらず та 始末 використано попередні словникові матеріали. Зіставлення з まだしも та きらいがある є авторським аналізом наявних речень. [Джерела v144](../audit144/sources.md)
- Нові спроби відкрити зовнішній словник і виконати пошук завершилися помилкою сервісу. Для решти рішень доказом є авторський контекстний розбір, а незалежна мовна звірка залишається відкритою.

Нові пояснення написано для застосунку. Для порівнянь відредаговано пунктуацію й окремі формулювання японських прикладів. Походження успадкованих матеріалів залишається предметом окремого аудиту.

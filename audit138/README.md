# Відтворення v138

Основа — повний v137. Змінюється тільки CSS у 比較 та видимий номер версії; весь JavaScript і навчальні дані байтово незмінні.

```sh
python3 audit138/build.py
node --check audit138/app.js
npm install --no-save playwright@1.56.1
npx playwright install --with-deps chromium
node audit138/browser.cjs
python3 audit138/publish.py
```

Браузерний огляд: 360/412/1280px; світла тема 100%/125%, темна тема й примусова світла тема; фактичні колір, жирність та розміри в картках слів і граматики, прикладах/перекладах і поясненнях порівнянь. Збережено виділення заголовків і ключових термінів. Окремо перевіряються reload списку та видалення позиції. Потрібний CJK-шрифт; скріншот /tmp/v138-comparison.png. Це локальна візуальна зміна, новий мовний аудит не виконується.

publish.py вимагає фінальний SHA-256 і 12 успішних браузерних сценаріїв. Після публікації звірити Git blob SHA повного HTML, аудиту та актуальної документації. Історичні звіти не переписувати.

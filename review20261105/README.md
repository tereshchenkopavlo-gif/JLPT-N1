## Відтворення

Потрібні Git-об’єкти гілок зі знімка api-state.json, Python, Node, Playwright 1.56.1 і Chromium 141.0.7390.37. За відсутності об’єктів отримати їх із доступних гілок/commit; не підміняти знімок новішими вершинами.

```sh
npm install --no-save playwright@1.56.1
npx playwright install chromium
node review20261105/probe.cjs
python3 review20261105/derive.py
python3 review20261105/public_inventory.py
python3 review20261105/check.py
```

`probe.cjs` виконує незмінений JS поточного HTML у новому ізольованому браузерному контексті; перебирає всі 3914 reading-пули й генерує по одному конкретному meaning-питанню для кожної граматики. Вибір першого прикладу, типу питання та seed зафіксовані лише в діагностиці. Це не Android/Windows-тест.

`probe.json` є локальним відтворюваним сирим знімком; не публікується як додаткова масова копія навчальних полів. `derive.py` зберігає ID, причини, хеші та власні редакторські спостереження. Він не робить мовних висновків автоматично: поіменні рішення внесені в grammar-decisions.tsv після читання варіантів.

`public_inventory.py` читає зафіксовані SHA, а не поточні змінні вершини. api-state.json містить окремі датовані спостереження API: видимість, гілки, 243 запусків і результати 67 запитів артефактів. Це відтворюваний історичний знімок; пізніше API може показати інший стан. Вміст ZIP не завантажувався, недосяжні об’єкти/видалені refs і зовнішні копії не перевірялися.

`check.py` перевіряє внутрішню узгодженість цих доказів та незмінність застосунку й попереднього обліку. Він не перетворює авторський перегляд на незалежну експертизу й не закриває C11/C16/походження матеріалів.

# Пробна редакція десяти японських визначень

6 листопада 2026, Asia/Tokyo. У пробній збірці на основі v152 до правки 先日 додано десять визначень. Для цих десяти ID змінено лише японське визначення. Японські приклади й українські переклади, позначки частин мови, ідентифікатори та граматика збігаються з v152.

| ID | Слово | Що уточнено |
|---|---|---|
| 122 | 購入 | Купівля товарів і послуг |
| 131 | 再現 | Відтворення та повторна поява того самого явища |
| 144 | 支持 | Підтримка позиції та фізична опора |
| 184 | 縮小 | Активне зменшення й зменшення самого масштабу |
| 203 | 振込 | Переказ коштів на рахунок, зокрема поза оплатою покупки |
| 264 | 展開 | Розгортання діяльності та розвиток подій |
| 267 | 店舗 | Торгова або сервісна точка як приміщення чи заклад |
| 268 | 転送 | Переадресація та передавання даних |
| 293 | 破壊 | Руйнування предмета, середовища або порядку |
| 313 | 比較 | Виявлення і спільних рис, і відмінностей |

Словникова звірка підтримала повторну появу для 再現, фізичну опору для 支持 і активне розгортання для 展開. Другий приклад 再現 містить іменникову сполуку 不具合の再現条件. Він сам по собі не показує неперехідної конструкції з явним підметом.

# Накопичувальна редакторська проба

До попередньої проби з перекладами додано 21 правку карток. У цьому проході змінено 11 японських визначень, 8 українських глосів та 2 примітки про вживання. Точний перелік полів наведено в `CARD_EDITS` у [trial.py](trial.py).

Для 次第 визначення тепер розділяє іменникове значення, залежність після іменника та негайну наступність після основи дієслова. У 精神 додано засадничу ідею, яку показує приклад про засновника. Для 批判 визначення охоплює також критичний розгляд і оцінювання. [精神](https://kotobank.jp/word/精神-86016) · [批判](https://kotobank.jp/word/批判-612181)

Накопичувальна збірка містить зміни для 80 із 82 ID, щодо яких запропоновано правки. Це охоплення ID. Деякі початкові пропозиції реалізовано частково, наприклад для 同士 уточнено визначення, а позначку частини мови збережено. Для 正義 не внесено запропоноване уточнення про внутрішній канал, якого речення прямо не називає. Для 直接 збережено 名詞 через відтворену втрату завдання reading після додавання 副詞. Обидва ID лишаються окремими редакторськими рішеннями.

Перевірено, що відносно попередньої проби змінилося рівно 21 зазначене поле. Для 22 прикладів одинадцяти оновлених визначень рушій повернув новий ключ і по три різні за текстом альтернативи. Чотири контекстні завдання C11 повторно пройшли перевірку. Це технічна перевірка прив’язки, а мовна якість автоматичних альтернатив потребує окремої оцінки. Браузерне приймання та незалежну мовну оцінку ще не проводили. Робоча версія v152 і чинний реєстр аудиту залишаються основою.

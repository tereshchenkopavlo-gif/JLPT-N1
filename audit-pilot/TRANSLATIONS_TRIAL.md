# Пробна редакція українських перекладів

У збірці `trial-translations.html` оновлено по одному перекладу для 26 карток. Зміни спираються на повторне зіставлення перекладу з повним японським реченням. Для окремих пунктів прийнято коротше формулювання, ніж у первинній редакторській пропозиції. Ця партія охоплює лише поля перекладу прикладів. Зокрема, запропоноване окреме уточнення японського визначення 提案 ще не внесено.

- **視点 (148).** Передано початок прояснення суті проблеми, який виражає 見えてきた.
- **視野 (149).** «Досвід за кордоном» зберігає ширше 海外経験.
- **資源 (151).** У перекладі явно зазначено частку енергоресурсів, яку Японія імпортує.
- **同情 (279).** 相次いだ передано як послідовні висловлення співчуття. Попередній переклад описував зростання кількості людей.

Точні формулювання й індекси прикладів зафіксовано в `TRANSLATION_EDITS` у [trial.py](trial.py). Порівняння з попередньою пробою підтвердило зміни лише цих 26 полів перекладу. Виклик функції відображення карток у Node.js підтвердив відповідність японського тексту й українського перекладу для обох прикладів кожної з 26 карток. Синтаксис JavaScript і попередні чотири контекстні завдання перевірено повторно. Браузерне приймання та незалежну мовну оцінку не проводили.

python audit-pilot/trial.py --out /tmp/jlpt-v152-trial
node audit-pilot/follow-up.cjs /tmp/jlpt-v152-trial/trial-translations.html --meaning

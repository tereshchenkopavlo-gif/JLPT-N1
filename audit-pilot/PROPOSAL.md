# Порівняння методик аудиту лексики

Основа пілота — v152. Авторський перегляд охоплює 120 із 3914 карток. Для решти 3794 карток наведені оцінки кількості партій, окремо від аудиту порівнянь, вправ і незалежного приймання.

| | Чинний процес | Запропонований пілот |
|---|---|---|
| Порядок | Послідовні ID, поіменний мовний перегляд і повний HTML після партії | Один скан усієї бази, черга за ризиком, спільний перегляд пов’язаних слів, пакетний випуск |
| Орієнтир за обсягом | 30–60 карток на партію, приблизно 127–64 партії | 200–500 карток на підготовлену партію, приблизно 19–8 партій за умови повного мовного опрацювання кожної |
| Використання доказів | Історичні рішення й контрольні суми карток | Звірка історичних хешів і окремі хеші форми, змісту, прикладів та залежностей |
| Ризик для якості | Нюанси між близькими словами можуть розглядатися в різних партіях | Евристики можуть дати пропуски чи хибні тривоги. Контроль через поіменні рішення, словники й корпус, повторне читання спірних випадків |

Технічна підготовка 200–500 карток і повний мовний перегляд такої партії — різні обсяги роботи. Оцінка 8–19 описує кількість повних партій за заданого розміру, без прогнозу календарного часу. Пілот вимірює підготовку на 200 картках та мовний перегляд на зафіксованій підвибірці. Рівність якості й прискорення повного мовного аудиту потребують окремого порівняння.

Рівні ризику: високий — структурна помилка або щонайменше чотири сигнали, середній — два чи три сигнали, низький — нуль або один сигнал. Сигнали охоплюють багатозначність, варіанти читання, омографи, близькі пари, стиль, нетипову форму та контекстні переклади. Семантичні зв’язки беруться з явних порівнянь і однозначно розв’язаних посилань. Спільний тег допомагає навігації, але сам по собі не встановлює синонімії.

Поля стану окремі: технічний, авторський мовний, незалежний і додаткова перевірка. Історичний запис без збігу хешу лишається в історії. Для наступних переглядів зміна читання чи форми спрямовує до повторної перевірки вправ і посилань, зміна прикладу — перекладу й прив’язаних завдань, зміна порівняння — його двох карток. Перевірки незмінних полів можна переносити лише в межах задокументованого доказу.

Рішення про основний процес приймається після результатів пілота. Пілот ведеться окремо від релізу HTML і чинного реєстру.
